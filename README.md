## 说明

双击运行软件，程序会常驻系统托盘。

按 Alt+A 开始截图；移动鼠标选择窗口，按 Tab 切换窗口/元素模式，也可按住左键自由框选。

选区完成后：
- √：复制到剪贴板并自动保存
- 保存图标：选择位置另存为
- ×、右键或 Esc：取消截图

按 Alt+V 打开剪贴板历史，可查看文字、图片和文件记录；双击记录可重新复制，也可右键置顶、删除或清空。

右键系统托盘图标，可修改截图热键、保存位置、暂停剪贴板记录、设置开机启动或退出软件。
