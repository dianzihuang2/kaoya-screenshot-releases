# 烤鸭箱

Windows 单文件截图、剪贴板历史、录屏与待办工具。原名“烤鸭极简截图”，文件名和仓库地址保持不变以兼容旧版更新。

## 下载

请从 [Releases](https://github.com/dianzihuang2/kaoya-screenshot-releases/releases/latest) 下载 `KaoyaScreenshot.exe`。

- 当前版本：v1.1.8
- 文件大小：38,382,080 字节
- SHA-256：003EDB2BA6A64AC5355E7EF256D40468AFAE623799E0E31E9FE23ED7E186B94D

## 功能

- Alt+A：截图并复制、保存或贴图。
- Alt+Q：打开剪贴板面板，分别管理文字、图片、文件和待办；支持透明度、贴边吸附、展示区缩放固定和 Windows 任务栏最小化。
- Alt+W：启动独立录屏，支持选区、系统声音、麦克风和 MP4 输出。
- 剪贴板面板支持默认、酷拉皮卡和 Chiikawa 主题；每次启动使用默认主题。
- 待办支持日期、月历、日子名称和提醒。

## 使用说明

程序启动后常驻系统托盘。左键单击托盘图标打开面板，关闭面板后可再次打开。双击剪贴板记录可重新复制，右键可置顶、删除或清空；安装更新前会校验文件大小、SHA-256、产品名称和版本。

便携 OCR 已停止提供。

## 许可

录屏功能使用 OBS Studio；对应源码和构建说明见 [obs-kaoya](https://github.com/dianzihuang2/obs-kaoya)。本项目按 GPL-2.0-or-later 提供。

## 更新设置

托盘菜单中的更新功能默认每 24 小时检查一次，也可手动立即检查。程序不会在未确认的情况下直接安装更新。
